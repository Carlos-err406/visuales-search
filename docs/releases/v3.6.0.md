# Visuales 3.6.0

## Interrupt All Downloads

- Stop all running and queued transfers from the Downloads toolbar or tray popup, with confirmation before anything is interrupted.
- The action includes CLI downloads and transfers hidden by the current filter. Completed downloads, history, and partial files are preserved so interrupted transfers can be resumed individually.
- Stopping queued work and active downloads happens under the shared queue lock, preventing the next queued transfer from starting during the operation.
- The existing `visuales tasks cancel --all` command uses the same bulk operation. Failures are reported per transfer without preventing other downloads from being interrupted.
- Late worker updates cannot restore an explicitly interrupted task to running or completed.

Existing CLI options, download defaults, and shared task history remain compatible. macOS installers retain the existing per-app approval requirement.
