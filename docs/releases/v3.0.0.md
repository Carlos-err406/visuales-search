# Visuales 3.0.0

## Breaking CLI Change

`--exclude` has been removed. Use `--ignore` in commands and scripts:

```sh
visuales download "https://visuales.uclv.cu/Movies/Example/" \
  --ignore '*.jpg' --ignore '!poster.jpg'
```

Rules now follow gitignore-style ordering: later matches override earlier rules, and `!` includes a match again. Paths are relative to each selected folder. Comments, directory rules, escaped names, and root-relative patterns are supported. Case-insensitive matching and comma/brace shorthand remain available. Explicitly selected file URLs still download regardless of ignore rules.

Existing task records and preferences remain readable. Resumed and queued tasks keep their saved rule lists; no migration or cache reset is required.

## Desktop

- Search and library rows show shared CLI/desktop download statuses, with fresh per-file progress where available. Completed labels appear only on exact transfer targets; ancestors do not show "Contains ..." labels.
- Quitting with running or queued transfers asks for confirmation. Quitting stops only this app instance's workers, preserves resumable partial files, and leaves external CLI transfers running.
- Settings includes persistent Ignore rules for new desktop transfers. CLI defaults and existing task options are unchanged.
- Settings info buttons open persistent help on click, tap, or keyboard activation. Escape, outside click, and the close button dismiss help; only one panel opens at a time.

## Distribution

CLI and desktop share version 3.0.0. Desktop installers cover macOS Apple Silicon and Intel, Windows, and Linux. Signed in-app updater assets and Homebrew formula/cask updates are published by CI. macOS builds remain ad-hoc signed, not notarized, and require the existing macOS approval flow.

Menu bar progress remains in the future-feature bucket and is not part of this release.
