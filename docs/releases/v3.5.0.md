# Visuales 3.5.0

## Retry Failed Files

- Retry one failed file or all failed files from the Downloads inspector without creating a new task or downloading completed files again.
- Retries retain the original destination, options, history, and aggregate progress. Available on stopped transfers only, with existing partial files reused where possible.
- CLI: `visuales tasks files <task> [--json]` lists recorded file paths and statuses. `visuales tasks retry <task>` retries all failed files; repeat `--file <path>` to select specific failures.
- Ordinary Resume continues to resume the whole transfer.

## Review Before Downloading

- Search's context menu and selection footer offer an optional Review Download dialog. Direct Download and Queue remain unchanged.
- Inspect included files and ignored files or subtrees before starting. Sizes distinguish known, approximate, and unknown data, with an advisory available-space warning.
- Start or queue using the reviewed destination and settings, retained for ten minutes even if defaults change in the meantime.
- CLI: `visuales download "<url>" --dry-run [--json]` reviews metadata without creating a task or output directory.

Existing CLI options, download defaults, and shared task history remain compatible. macOS installers retain the existing per-app approval requirement.

Windows task-history updates also tolerate brief file locks during atomic replacement, without deleting the previous history or hiding persistent write failures.
