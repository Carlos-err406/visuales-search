# Visuales 3.8.1

## Retry All

- Retry failed downloads from the Needs attention group with one action. Matching failed transfers join the existing queue; manually interrupted downloads stay stopped.
- Retry all failed files from the transfer inspector's Needs attention header, even when the group is collapsed.
- New failed-file records show how many retries were used, such as "5 of 5 retries used".

## Retry Reliability

- Connection and request timeouts, temporary unavailable pages, HTTP 408, and transient verification failures now use the shared file retry budget in desktop and CLI.
- Five configured retries means one initial attempt plus up to five retries. Permanent errors such as HTTP 404 still fail immediately.
- Verified completed files and resumable partial data are preserved. Retry claims reject tasks that are no longer failed.

## Compatibility

Existing downloads keep the settings saved when they were created, including their retry limit. Changing desktop defaults does not rewrite older tasks. Historical attempts were not recorded, so retry counts are shown only for newly recorded attempts. Existing workers adopt the fixes when restarted with this version.

CLI commands, download defaults, and cache locations are unchanged.
