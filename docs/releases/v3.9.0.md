# Visuales 3.9.0

Find recent library items, adjust active download concurrency, and open completed downloads directly from notifications.

## Search and Library

- Sort by name or modification date, newest or oldest first. The selected order is remembered in Search and folder-rooted windows.
- Listings show the date without the time. Folders stay first, and items with unknown dates stay last within their group.
- Older caches acquire missing dates for visible items as needed. Background indexing order is unchanged.
- Removed the inline refresh icon from listing rows; Refresh cache remains in the context menu.

## Downloads

- Saving Concurrent files now applies to this desktop instance's running and queued transfers, including selective retries.
- Increasing the limit starts additional pending files immediately. Decreasing it lets active files finish before enforcing the lower limit.
- The applied limit is saved for resume. Other transfer options, progress, queue order, CLI workers, and other app instances are unchanged.

## Notifications

- Completed downloads offer Show in Finder on macOS, Show in File Explorer on Windows, or Open containing folder on Linux where supported.
- The action opens that transfer's recorded destination, not the current selection or a later default folder. Missing or moved folders show a warning.
- Existing notification preferences and foreground suppression are preserved. Actions are session-only and depend on OS notification support; they do not relaunch a quit app.

CLI and desktop share version 3.9.0. CLI flags and defaults are unchanged. Existing downloads and cached library data remain compatible.

macOS builds remain ad-hoc signed, not notarized. First installation may require approval in System Settings > Privacy & Security. Linux in-app updates require the AppImage.
