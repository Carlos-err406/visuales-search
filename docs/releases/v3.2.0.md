# Visuales 3.2.0

## Desktop

- Get native notifications when a desktop transfer completes or fails after its retries, while the main window is in the background.
- Control completion and failure alerts independently in Settings > Notifications. Both are enabled by default and follow your system notification permissions and Focus/Do Not Disturb settings.
- Notifications apply only to transfers started or resumed from the desktop app. CLI-only transfers, historical downloads, manual interruptions, and repeated status polling stay quiet.
- Linux notification servers with action support can open the relevant download from an alert. The current macOS and Windows notification adapter does not support task-specific click navigation.
- Initialize macOS notification identity once so subsequent alerts can be delivered normally.

## Compatibility

CLI commands, transfer defaults, shared task storage, and app quit behavior are unchanged. Existing desktop settings are preserved, with notification preferences added automatically.

Update through the desktop app, GitHub installers, or the Homebrew cask. macOS builds remain ad-hoc signed and may require approval in System Settings > Privacy & Security on first installation. Allow notifications in macOS System Settings when prompted.
