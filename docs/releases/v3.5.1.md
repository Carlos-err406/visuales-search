# Visuales 3.5.1

## Reliable Resume Progress

- Resuming a transfer restores verified completed files and existing partial bytes before downloading, instead of rebuilding progress from zero.
- Unchanged, explicitly verified files are reused locally without probing every file again. Missing, modified, and unverified files still follow the normal verification path.
- Failed transfers persist their reconciled byte totals, including resets to zero, without losing completed sibling files or leaving stale active downloads behind.

## Stronger Completion Checks

- Cached sizes no longer certify a file as complete. Conflicting server metadata and transfer sizes trigger the final verification and missing-tail repair pass.
- The last repair attempt is verified too. A complete partial file can be promoted after a valid end-of-file check without getting stuck requesting bytes beyond the end.
- Invalid range replies and HTTP 416 responses without a total cannot certify completion. When the server cannot prove completion, the transfer fails with an explanation and keeps partial data for a later retry.

These fixes apply to both CLI and desktop through the shared engine. Older completion records need one verification pass before qualifying for fast local resume. Download defaults, CLI options, and shared task history remain compatible.

macOS installers retain the existing per-app approval requirement in Privacy & Security.
