# Visuales 3.8.2

File indexing keeps moving when the server's listado.html points to removed folders.

- Missing or inaccessible folders no longer trigger a global indexing pause. Network failures and server throttling still use backoff.
- Missing branches defer their descendants together instead of repeatedly requesting every removed subfolder. Previously cached files remain searchable; deferred work can recover when the parent returns.
- Existing scan checkpoints recover automatically from missing-folder backoffs without restarting the index from zero.
- Slow listing responses count toward request pacing, avoiding an extra wait after every response. Background requests remain serial and respect crawl delays.
- Incomplete scans can refresh the folder index the next day even when some folders remain unavailable.
- Settings distinguishes skipped, unavailable folders from successfully indexed folders.

The shared indexing fixes apply to desktop and CLI. No download settings, stored transfers, or command-line flags change.
