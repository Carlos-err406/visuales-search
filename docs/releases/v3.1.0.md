# Visuales 3.1.0

## Desktop

- Monitor shared CLI and desktop transfers from the menu bar or system tray while Visuales runs.
- macOS and Windows include a compact Mini Downloads popup with byte-based progress, file counts, downloaded/total size, and fresh transfer speed.
- Open download folders, interrupt running or queued transfers, and resume interrupted or failed tasks directly from the popup.
- Filter by status from the header. Active is the default; other filters display a small indicator. Combined speed lives in the footer.
- The popup is 560px tall when screen space allows. Status labels share the title line, leaving more room for transfers.
- Linux and right-click access use a native status menu with Open Downloads and Quit actions.
- Fix macOS updater restarts that could leave Visuales running in the Dock without a visible window. Startup and Dock reopen now restore the main window.

## Compatibility

CLI commands, download defaults, and shared task storage are unchanged. Quit still warns about active work and stops desktop-owned workers; this release does not add close-to-tray or background downloading after exit.

Install through the existing desktop updater, GitHub installers, or Homebrew cask. macOS builds remain ad-hoc signed and may require approval in System Settings > Privacy & Security on first installation.
