# Visuales 3.9.1

More reliable file indexing and clearer interrupted download history.

## File Indexing

- Unavailable folders are counted as skipped. Temporary failures are retried fairly, with at most three attempts per scan, instead of retrying the same failing folder indefinitely.
- Persistent failures remain visible as exceptions and can be retried manually or on a later scan. Previously indexed files remain searchable.
- The status distinguishes a finished scan with exceptions from an active retry delay and shows deferred folders and the next retry when applicable.
- Manual retry and refresh continue to respect server-requested retry delays.

## Downloads

- Interrupted, failed, and queued downloads without recorded totals can show an approximate total from a fully cached folder listing, respecting the transfer's saved ignore rules.
- Incomplete caches do not invent folder totals. Cached estimates never change recorded download progress or mark files complete.
- Error and Interrupted are separate collapsible groups in Downloads, file details, and the menu bar/tray popup. Each group remembers its collapsed state.
- Existing Needs attention collapse preferences carry over to both new groups. Retry all only targets errors; interrupted transfers retain queue and resume controls.

CLI and desktop share version 3.9.1. CLI flags and defaults are unchanged. Existing downloads and cached library data remain compatible.

macOS builds remain ad-hoc signed, not notarized. First installation may require approval in System Settings > Privacy & Security. Linux in-app updates require the AppImage.
