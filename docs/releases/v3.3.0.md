# Visuales 3.3.0

## Downloads

- Inspect a transfer in a resizable, non-modal side panel without leaving the Downloads list.
- Browse per-file progress, sizes, errors, and verification status in collapsible Downloading, Pending, Needs attention, and Finished groups.
- See per-file speed, active download connections, and completed/total chunks when parallel ranges are available. Stale and finished metrics disappear automatically.
- Keep running transfers first, queued transfers next, and transfer history last.
- Reorder waiting downloads with Start next, Move up, and Move down, with animated movement and reduced-motion support. Active downloads are never interrupted by reordering.
- The tray popup now starts with All statuses selected.

## Search

- Download or queue an individual folder or file directly from its row.
- Stage multiple items with Ctrl/Cmd selection or Shift range selection instead of checkboxes. Batch actions appear only while items are staged.
- Press Escape to clear the staged selection. When a preview or menu is open, Escape dismisses that overlay first and preserves the selection.

## CLI and Shared Engine

- Use `visuales tasks queue`, `visuales tasks move <id> <position>`, and `visuales tasks next <id>` to inspect and reorder the same persistent queue used by desktop.
- Queue claiming and reordering share a lock so only the selected next worker starts.
- Both CLI and desktop record per-file history in the shared cache. Existing historical transfers are not re-scanned or given invented details.
- Existing commands and download defaults are preserved. Workers already running on an older release must be interrupted and resumed with the updated version to adopt queue ordering and detailed connection telemetry.

Update through the desktop app, GitHub installers, npm, or Homebrew. macOS builds remain ad-hoc signed and may require approval in System Settings > Privacy & Security on first installation.
