# Visuales 3.4.0

## Library Windows

- Open image and text previews in their own windows, including in the background while continuing to search. Opening the same resource again reuses its window.
- Zoom, pan, fit, and browse images; find text and toggle wrapping in text previews.
- Open a folder in a new window with the same Search, Downloads, and Settings interface. Library browsing and searches are scoped to that folder's branch.
- Right-click Search items for preview, folder-window, Download Now, Add to Queue, refresh, and Copy Link actions. Multi-selection actions apply to the selected items. Completed local files can be revealed in the system file manager.
- Cached previews open without waiting behind unrelated network requests. Preview fetches are bounded and coalesced, with visible waiting/loading states.
- Preview older Spanish synopsis and subtitle files encoded as Windows-1252/Latin-1, plus BOM-marked UTF-16. Existing UTF-8 support remains; text is inert and binary content is rejected.

## Downloads

- Replace the Downloads status dropdown with collapsible Downloading, Pending, Needs attention, and Finished groups. Text filtering, queue ordering, and the transfer inspector remain available.
- Fix resumed-transfer totals in both CLI and desktop: completed files already on disk contribute their actual bytes, rounded listing estimates are reconciled on completion, and final progress updates are no longer lost to telemetry throttling.

Existing running workers keep their loaded engine. Start a new run or interrupt and resume with the updated version to pick up the progress fix. Downloaded files, shared history, CLI options, and transfer defaults are preserved.

Update through the desktop app, GitHub installers, npm, or Homebrew. macOS builds remain ad-hoc signed and may require approval in System Settings > Privacy & Security on first installation.
