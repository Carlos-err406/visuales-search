# Visuales 3.3.1

## Desktop

- Remember the main window's size and maximized state between launches. The tray popup is excluded, and restarting still presents the main window rather than restoring a hidden or minimized window.
- Expand cached folders faster when browsing the full library with an empty search. Loading and error indicators no longer rebuild the entire tree, URL normalization is reused, and natural-name sorting avoids repeated collation setup.
- In an isolated development-browser comparison using a 29,955-entry cached index, first folder expansion improved from about 1.5-1.7 seconds to 0.4-0.46 seconds. Timings vary by machine and build.

CLI commands, transfer defaults, download behavior, and shared cache locations are unchanged.

Update through the desktop app, GitHub installers, npm, or Homebrew. macOS builds remain ad-hoc signed and may require approval in System Settings > Privacy & Security on first installation.
